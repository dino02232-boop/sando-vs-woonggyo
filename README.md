# 산도와 웅교의 NBA 데이트

산도(LA 레이커스 · 루카 돈치치)와 웅교(골든스테이트 워리어스 · 스테판 커리) 두 사람만을 위한
2026-27 NBA 전용 사이트입니다. 첫 화면은 돈치치 vs 커리 전신 액션 사진의 VS 포스터이고,
사진을 누르면 그 진영(프로필)으로 입장해 **경기 화면(상단)** 과 **채팅방(하단)** 을 반반으로
쓰면서 경기를 같이 봅니다. 전체 디자인은 밝은 화이트 톤입니다.

- 배포 주소: https://dino02232-boop.github.io/sando-vs-woonggyo/

## 화면 구성

**1. 첫 화면 (VS 포스터)**
- 상단 타이틀 `산도와 웅교의 NBA 데이트`
- 왼쪽: 산도 · LAL — 루카 돈치치가 레이커스 유니폼으로 드리블하는 전신 액션
- 오른쪽: 웅교 · GSW — 스테판 커리가 슛을 던지는 전신 액션
- 흰 톤 워시 위에 대각선 균열 + 가운데 `VS`, 각 진영 하단에 `산도 입장 →` / `웅교 입장 →` 버튼
- 사진·카드 어디를 눌러도 해당 프로필로 입장합니다.

**2. 입장 후 (상단 경기 화면 50% + 하단 채팅 50%)**
- 상단 맨 위 **경기 전환 바**: `GSW @ DAL` | `LAL VS UTA` 두 카드가 항상 보이고,
  누르면 그 경기 화면으로 즉시 바뀝니다(진행 중이면 빨간 점 + 쿼터·스코어 표시).
  산도로 입장하면 레이커스 경기, 웅교로 입장하면 워리어스 경기가 기본 선택됩니다.
- 그 아래 **선택된 경기 스코어보드**: 팀 로고·점수·쿼터와 남은 시간·경기 전/종료 상태·전적
- **핵심 정보 줄**: 돈치치/커리 시즌 평균과 출전 상태, 부상자 수, 이 경기 승부예측 버튼
- 나머지 영역은 **그 경기의 실시간 문자중계 피드**(최신 플레이가 위, 스크롤 가능).
  경기 전에는 팁오프까지 남은 시간과 그 팀의 최근 5경기를 보여줍니다.
- 하단 50%: 산도/웅교 채팅방 (말풍선은 내가 오른쪽, 상대가 왼쪽 / 팀 컬러 포인트)
- 상단 탭: `💬 채팅` · `🟣 레이커스` · `🔵 워리어스` · `⚡ 맞대결`

**3. 탭 상세**
- 레이커스 / 워리어스: 팀 전적·순위·홈/원정·평균 득실점, 선수 카드(시즌 평균·슈팅 스플릿),
  직전 경기, 최근 5경기, 다가오는 경기, 부상자 명단
- 맞대결: 시즌 상대전적(1-1)과 두 경기 상세, 남은 맞대결 2경기, 팀 지표 비교,
  돈치치 vs 커리 비교, 서부 컨퍼런스 순위

## 실시간 데이터

- 스코어/쿼터/남은 시간: `https://site.api.espn.com/apis/site/v2/sports/basketball/nba/scoreboard`
- 문자중계: `https://site.api.espn.com/apis/site/v2/sports/basketball/nba/summary?event={gameId}`
- 25초마다 자동 갱신 + 새로고침 버튼, 탭이 백그라운드면 폴링을 멈춥니다.
- 네트워크·CORS 문제로 실시간 호출이 막히면 `js/data.js`의 스냅샷 값으로 안전하게 대체합니다.

`js/data.js`는 ESPN 공개 API에서 **2026-11-19 09:15 KST 기준**으로 수집한 실제 2026-27 시즌
기록입니다(전적·순위·일정·박스스코어·부상 리포트). 지난 시즌 수치가 섞이는 통계 API 대신
팀 일정/경기 박스스코어/게임로그로 교차 검증했습니다.

## 저장 방식

정적 GitHub Pages라 서버가 없습니다. 그래서 채팅, 승부예측 픽, 선택한 프로필은
브라우저 `localStorage`에 저장됩니다(새로고침해도 유지, 기기마다 따로 저장).

- `nbadata.profile` — 현재 활동 프로필(산도/웅교)
- `nbadata.chat` — 채팅 메시지
- `nbadata.picks` — 경기별 승부예측 픽

## 파일 구조

```
index.html
css/styles.css
js/data.js      # ESPN 실데이터 스냅샷

assets/         # 선수 사진, 팀 로고, 공유 이미지

```
